# ALM Anagram Toolkit: installers

This repo holds only the **installers** for ALM Anagram Toolkit, Anagram Data's tool for comparing and deploying Power BI semantic models and reports. The source code is kept private.

**[Download the latest version](https://github.com/AnagramData/alm-toolkit-releases/releases/latest)**: run `ALM-Anagram-Toolkit-<version>-Setup.msi`. It upgrades any earlier version in place.

From 2.0.4, the app checks this page at startup. When a newer version is out it shows **Update** in its top bar, and one click installs it and reopens the app.

Needs Windows with the Microsoft Edge WebView2 Runtime, which comes with Windows 11 and most Windows 10 PCs. The installer is unsigned, so Windows SmartScreen may warn: choose More info → Run anyway.

Releases are published here automatically by the private repo's build.
